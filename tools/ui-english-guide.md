# 画面の英語ガイド

日本語は常に残し、短い英語を上段に表示します。右上のENで切り替え、端末の `tsuyaku-english-guides-v1` に保存します（初期値はON）。会話の原文、翻訳、読み上げ本文、入力値はガイドの対象外です。英語ガイドはAIを呼びません。認証済みの画面表記APIを起動時・表示中は約60秒ごと・画面復帰時に取得します（最短45秒間隔）。

## 管理元

既存スプレッドシートの `ui_translations` を再利用しています。A:Jの既存列を保持し、K:Nに次を追加しました。

- K `enShort`: 通訳君の短い英語
- L `uiKey`: 日本語から作った安定した識別子
- M `uiStatus`: `ready` は操作の文脈で確認した表記、`reused` は既存訳
- N `uiSource`: 元のシート・行、または通訳君用の表記

`ruby_dictionary.enRuby` は辞書カードの短い英語にも再利用しています。利用者名、会話本文、ルーム記録などは取り込みません。

## シート編集の自動反映

ui_translations の enShort を編集すると、再公開なしで次の定期取得時に反映します。同じ日本語が複数行ある場合は最上段の uiKey 付き行を使います。空欄にするとその英語を非表示にします。取得失敗時は端末に保存した前回の表記、初回は同梱データを使います。シート全体を公開せず、既存の認証付き辞書接続で画面表記列だけを返します。

`tools/ui-sheet-source.json` は今回取得した既存表記のスナップショット、`tools/ui-short-overrides.txt` は操作単位で整えた英語です。更新したシートの確認済み表記を取り込み、この2ファイルを更新した後、`node tools/build-ui-labels.mjs` と `npm test` を実行して公開します。`tools/ui-labels-publish.json` は出典を含む生成結果、`web/ui-labels.js` はアプリに同梱するデータです。

## 描画

`web/ui-english.js` は追加・変更されたUIだけを監視します。空の英語用spanのCSS生成コンテンツに英語を表示し、元の日本語テキストノードを保持します。このため `textContent`、検索、コピー、読み上げに補助英語が混入しません。日本語と英語はそれぞれのlangを指定します。アイコンボタンの説明と管理画面の確認ダイアログもON/OFFに合わせます。
