# 既存スキャンの翻訳配置修復

保存本文と表示時OCRの差がある架空資料を公開APIで登録し、390幅でuntranslated-sourceによる配置失敗を再現。本文は2段落あり、OCR行端の余分な文字で全訳文が非表示になっていた。

文字列90%以上一致・同一OCR行・余分な文字が最大4文字かつ行の8%以下という条件で座標を回復する。保存本文、訳文、金額、質問根拠は変更しない。別文章・大きな未対応行・文字PDFには適用しない。配置失敗中の英語準備数を非表示にし、翻訳データ取得と表示成功を混同させない。追加AIリクエストや画像送信は発生しない。

修正候補は実際の翻訳APIとOCRを使い、390/1280の両方でready、英訳1200 yen、PDF内表示、再試行不要を確認。45組の自動テストを通過。失敗時の準備数非表示と、他言語からの復帰は制御APIの画面試験で確認。試験資料は削除。公開後の検証結果は追記する。

添付された1年生通信そのものと実機Safariは未確認。この記録は同種の読み取り差を再現した試験であり、あらゆる配置エラーを解消した保証ではない。
