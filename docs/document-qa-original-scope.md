# 資料QA改善の元の30項目

当初の提案から抜粋。22〜26は今回の対象外。

| 優先 | 改善候補 | 確認したいこと |
|---|---|---|
| 1 | 資料QAの検証用質問セットを作る | 「1年」と「1年間」の言い換え、下校時刻、年間費用、複数項目、資料に答えがない質問を繰り返し確認できるようにする |
| 2 | 関連箇所の検索に意味検索を加える | 現在のキーワード検索に加え、資料と質問で使う言葉が違っても、同じ内容の箇所を見つけられるようにする |
| 3 | 複数の質問を項目ごとに検索する | 給食費・生徒会費・PTA会費をまとめて聞いても、それぞれの原文とページを出せるようにする |
| 4 | 表の見出しと各行を一緒に検索する | 月別の下校時刻や費用の内訳で、条件や金額の対応が崩れないようにする |
| 5 | iPad Safariで一連の操作を確認する | PDFの登録、目次、慣性スクロール、画面回転、質問入力、モーダルの開閉まで通して確認する |
| 6 | 資料QAの読み込みエラーを切り分ける | PDF取得、描画、目次生成、回答生成のどこで止まったかを、資料本文や質問を含めずに確認できるようにする |
| 7 | 保管庫に資料名検索を付ける | 資料が増えても、名前の一部からすぐに開けるようにする |
| 8 | 公開版の基本操作を自動で確認する | 保管庫が最初に開き、作成ボタンが保管庫にだけあり、PDF登録から質問・削除まで進めるかを公開ごとに確認する |

9. **根拠リンクから該当箇所を強調する。** ページ内で引用された段落や表の行を探す手間を減らす。
10. **検索の範囲を段階的に広げる。** 最初に見つけた箇所だけでは根拠が足りない場合、前後の段落や関連ページも探す。
11. **複数ページの根拠をまとめて表示する。** 年間費用のように複数ページを参照する回答から、各ページへ移動できるようにする。
12. **「それはいつ？」のような続けての質問に対応する。** 直前の質問で扱った項目を、次の質問でも参照できるようにする。
13. **合計金額の内訳と計算式を表示する。** 月額×回数、一度だけの費用、任意の費用を見分けられるようにする。
14. **PDF内の文字検索を付ける。** 目次に出ない語句も、該当するページを順に確認できるようにする。
15. **回答の再試行を簡単にする。** 通信が途切れた場合、同じ質問を入力し直さずに再試行できるようにする。
16. **PDFを最後に読んだページから再開する。** 同じブラウザーで資料を開き直したとき、続きから読めるようにする。
17. **最近開いた資料を上に表示する。** 日常的に使う資料へ戻りやすくする。
18. **期限と公開範囲を一覧で確認できるようにする。** 個人の保管庫と共通保管庫で、いつまで誰が開けるかを表示する。
19. **資料の並べ替えを付ける。** 資料名順、登録日の新しい順、期限が近い順で探せるようにする。
20. **共有を続けたままPDFを差し替えられるようにする。** 改訂時に目次・検索索引・回答の再利用データを更新し、古い内容で答えるのを防ぐ。
21. **作成時にPDFの状態を早めに知らせる。** 画像だけのPDFや文字を抽出できないPDFは、回答を作り始める前に分かるようにする。
22. **生徒側が字幕を受け取れる状態か表示する。** 先生が話し始める前に、接続や受信の状態を確認できるようにする。
23. **切断から復帰したときに直近の字幕を補う。** 再接続後に抜けた字幕を表示し、すでに受け取った字幕の重複を防ぐ。
24. **生徒の質問を先生側で一覧にする。** 講義中に届いた質問を、先生が区切りのよいところで確認できるようにする。
25. **字幕と要約の対応を見られるようにする。** 要約の項目から、その元になった発言に戻れるようにする。
26. **授業終了時に配布用の要約を作れるようにする。** 決まったこと、宿題、締切を見分けやすく整える。
27. **資料QAの費用を処理別に見えるようにする。** 資料作成、目次生成、質問回答のどこで費用がかかっているかを管理者画面で確認できるようにする。
28. **検索による入力トークンの削減量を測る。** 全文を渡した場合と関連箇所を渡した場合で、費用と根拠付きの回答率を比較する。
29. **月報に字幕配信と接続復旧の実績を加える。** 稼働回数や利用時間に加えて、授業で安定して使えたかを導入説明で示せるようにする。
30. **試験結果と公開履歴を管理者画面で確認できるようにする。** どの版でどこまで確認したかを見返せるようにする。
