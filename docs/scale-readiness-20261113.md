# 人数増加への準備（2026-11-13）

- 授業では参加人数と言語別人数を先に表示する。
- 9人以上の参加者は最初の8人だけを描画し、必要なときに全員を展開する。
- 途中参加で受け取る字幕履歴を授業120件、チャット80件に制限する。
- WebSocketの同報データは一度だけJSON化して各端末へ配る。
- `metricsOutput` に最大参加人数、言語別最大人数、履歴省略回数を含める。
- 100人の参加者要約と、150件中直近120件だけを返す自動試験を追加する。

既存の役割制御、最大100接続、翻訳待ち24件、同時翻訳2件、重複翻訳の統合、指数バックオフ再接続は維持する。今回、利用料金・AI予算の停止上限は変更しない。

次の実地確認は学校ネットワークで10人、30人、50人の順に行い、`metricsOutput.scaleReadiness`、翻訳待ち、再接続回数、表示時間を比較する。
