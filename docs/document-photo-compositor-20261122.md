# 写真翻訳と資料QAの描画共通化

資料QAのスキャンはHTML行の最小12px表示や密集判定の分岐を経由せず、写真翻訳の drawPhotoOverlay を共通利用する。元ページのキャンバスへ背景色を周辺から採取し、各OCR領域内で文字を折り返し・縮小・クリップして描く。全ページを白い本文ページに組み直さない。既存の縦書き/図形混在フラグでも古い大きな文字のHTML表示へ戻らない。透明な操作領域を同じ座標へ置いて訳文タップとアクセシビリティを維持。黄色根拠は共通描画で色を指定する。

取得済みのOCR座標と訳文を再利用する描画修正で、ページ画像を新たに外部送信しない。OCRの誤認識そのものは別の課題であり、この変更だけで認識精度の向上を保証しない。

候補版で公開APIの架空スキャンをポルトガル語翻訳し390/1280幅の表示・拡大・原文切替・全文確認が合格。46組テスト、縦書き/図形混在の成分検証、写真画素・黄色強調・二重文字なしを確認。元のPDF表・罫線・写真の回帰も両幅で合格。公開後の確認を追記する。
