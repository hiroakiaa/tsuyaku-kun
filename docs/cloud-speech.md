# フィリピノ語のWaveNet読み上げ

2026-10-20に接続・公開を確認済み。Text-to-Speech APIだけに制限したキーをCloudflareの暗号化シークレットに保存し、本番APIで音声生成、公開画面で辞書文例の再生と同一文のキャッシュ再利用を確認した。試験時の合計は98文字・音声生成2回。話者による発音品質の評価とAndroid・iOS実機での確認は未実施。

Cloudflare Workerの秘密 `GOOGLE_TTS_API_KEY` を設定すると、認証付き `/speech/status` が有効状態を返す。キーはGoogle Cloud Text-to-Speech APIだけに制限し、公開ファイル・Git・ログへ保存しない。既存の別アプリ用キーは利用しない。

対象はフィリピノ語・タガログ語のみ。Googleへ平文を送り、`fil-PH-Wavenet-A`、MP3、標準速度・音高で合成する。他の言語は従来の端末音声を使う。キー未設定時は従来動作を保つ。音声の自然さは実端末と話者による確認が必要。

全端末合計でUTC暦月50万文字、認証IDごとに5万文字を上限にする。日本時間では月初9時にリセット。1要求1200文字・4800バイトまで。Durable Objectのトランザクションで送信前に文字数を確保し、同時要求でも上限を超えない。失敗でもGoogle側の処理を否定できないため文字数は返さない。これはGoogleの無料枠残量や請求額ではない。他のアプリでの利用は含まない。

管理画面の概要に使用文字数と残量を表示する。本文・音声はサーバー保存せず、同じ文章の音声は開いているページのメモリー内だけで再利用する。上限24件・文字列メモリー換算8MB。ページ終了で消える。

単語の追従は音声の再生位置と推定単語時間による表示。強制アライメントではない。停止時はHTTP待機と音声再生を取り消し、遅い完了通知が次の再生へ影響しないよう世代番号で検査する。

確認：`npm test`。実サービス接続後は認証付きstatusと短いフィリピノ語の合成、実端末の再生・停止・再開を確認する。
