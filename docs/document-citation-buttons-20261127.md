## 変更
- ページ描画後に引用位置を調べて再度スクロールする直列処理を廃止。描画と引用位置の準備を並行し、マーカーをpending状態で配置してから、スクロール開始と同時に一括解除して左から伸ばす。
- 同じ引用の重複再生成を抑制。長距離の自動スクロール中にページ番号が途中ページへ切り替わる問題を、到達判定付きのナビゲーション状態で防ぐ。手動のwheel/touch/pointer操作時は自動判定を解除する。
- 「該当ページ」ラベルを左に置き、根拠リンクを薄い背景の角丸ボタンとして横並び・必要時折り返し。区切り線はボタン列の下へ移す。
- 追加済みの表示可能PDFページも、資料名＋相対ページ番号のボタンで元の該当ページへ移動できるようにする。旧文字だけの資料で表示ページが存在しない場合はリンクを偽造しない。
- 原文の黄色28%/multiply・枠なし・影なしは維持。新見出しの英西訳を同梱し他言語のUIラベル一覧も同期。費用影響はcost-review.md。
