# 翻訳の忠実さと待機処理の修正

ビルド: 20261029-faithful-pipeline-1

通常の日本語訳に、小学生向けの言い換え指示が混ざる経路を修正した。ja-easyを要求した場合だけ、そのキーに限定して平易化する。通常訳には適切な漢字と原文の語調を使い、対象者・学年・説明を追加しないよう指示する。文脈は語義の曖昧さを解くために用い、内容を補足しない。

一部の英語文が日本語欄へそのまま残った場合と、原文にない「小学生」「みなさん」などが追加された場合に確認用の警告を出す。固有名詞や引用は機械的に消さず、警告だけで誤訳率を計算しない。新しいAI判定や自動再翻訳は追加しない。

品質確認の生成側と集計側でバージョンがずれていた。共有定義とv1/v2/v3の受け入れを用い、未確認件数を明示する。確認記録がない場合の警告件数はnullとする。過去の本文がない履歴を後から確認済みにしない。

p50は中央2値の平均へ統一し、接続分析と利用集計の値を一致させる。p95はnearest-rankのまま。p50・p95の差し引きで個別の区間時間を推定しない。

認識と翻訳は端末内の最大2件のAI枠を共有する。翻訳を最大2件重ね、空き枠をFIFOで割り当てる。同一字幕の改訂は直列化し、字幕の位置は原文受付順で保持する。文脈に後の発話を混ぜない。停止と退室は待機・実行中の要求を取り消し、遅れた結果を画面やキャッシュへ反映しない。送信済みで費用が不明な場合は未計測として残す。

## 検証

- 単体・統合テスト: 品質バージョン、未確認値、中央値、指示の分離、警告の陽性・陰性例、AI枠上限、FIFOと取消、並行翻訳、逆順完了、未来の文脈の除外、背景停止。
- ブラウザー: 認識と翻訳を合わせて最大2件、訳の逆順完了でも原文順、JavaScriptエラーなし。
- 320×568・568×320・1024×600: 認識の長時間待機、内部記号の拒否、手動復旧、録音の再送なし。
- 390×844・844×390・1366×768: 二言語判定、翻訳方向、不確実な入力、手動入力。
- チャット・復旧・利用上限の既存テスト。

実際の会話での認識精度、翻訳正答率、速度改善率、相手端末への表示は別途実測が必要。提供元の長い応答時間と端末の枠待ちは分けて確認する。
