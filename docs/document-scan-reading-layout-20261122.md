# 密集スキャン訳文の可読性

行の元座標へ最小12pxの英訳を詰める方式では、本文が長くなったときの欠け・サイズ不統一が残る。密集した横書き本文は、同じ資料画面内の白いページに段落として組み直す。通常16px・行間1.55、見出し20px。横幅はプレビューに固定し、縦へ伸ばす。写真は端末で検出した領域を元画素から切り出して配置する（検出できない写真や複雑な装飾の完全再現は保証しない）。原文トグルは元ページへ戻す。短いページ、狭い表セル、同じ高さに複数列が多いページ、縦書き/図形文字混在は元配置を維持。

候補検証：実際のOCR・公開翻訳APIの架空20段落を390/1280で表示。16px以上、重なり0、横切れ0、ページ幅390/640、拡大時20pxを確認。46組のテストを通過。写真は合成画像の成分試験で1領域の画素が完全一致し、24段落と1箇所の黄色強調を維持。翻訳APIは追加せず取得済みの訳だけを再配置する。

この変更は元画像のピクセル位置を厳密に保つ表示とは異なり、密集本文の読みやすさを優先した再配置である。添付画像の原資料と実機Safariは未確認。公開後の結果を追記する。
