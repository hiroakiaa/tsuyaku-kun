# 20項目の改善・検証記録

対象版: 20261022-reliability-20-1。既存の予算上限・認証・参加承認・保存期限は維持する。
ブラウザー試験の通信切断、音声入力、翻訳モデルは明記したテスト用の再現。物理Android/iPhone・通信会社・Bluetooth・OS省電力の保証とは区別する。

| 項目 | 対応と検証 |
|---|---|
| 1 弱い回線・未達 | send例外・送信待ちバッファ過多は未送信扱い。受付・表示確認を区別。確認を使い切った場合は再確認でき、翻訳済みの文はAIを呼び直さず同期する。 |
| 2 回線切替 | オフライン中のcloseで自動復帰の権利を失う問題を修正。5ブラウザー試験で切断→online→履歴受信→双方向返信を確認。 |
| 3 ロック後受信 | 同じ会話の受信だけ復帰し、マイクは自動開始しない既存制御を回帰検証。実機のロック試験は残る。 |
| 4 OS省電力 | 背景では録音・待機処理を止め、復帰時は再認証・履歴同期。OSの強制終了は防げないため実機試験が必要。 |
| 5 マイク拒否 | 拒否・機器なし・使用中・時間切れを別の案内にし、サイト設定と文字入力を案内。許可を自動変更しない。 |
| 6 入力機器切替 | devicechangeで録音を止め、古い入力を破棄。次のONで入力を取り直す。イベント再現試験で確認。Bluetooth実機は未確認。 |
| 7 認識二重確定 | 同じ認識セッション・同じ結果番号・同じ文字の最終通知を重複除外。別の結果番号の同じ発言は消さない。 |
| 8 長文・否定 | 長いブラウザー認識結果を欠落なく上限内に分割。数字・否定・絵文字を含む長文の連結一致を検証。意味の翻訳精度とは別の検査。 |
| 9 同時発言 | 5人・複数言語の送信、遅い翻訳との順序、同じ言語の翻訳先重複除外を実処理で検証。無制限の負荷保証ではない。 |
| 10 古い版の上書き | 旧版の表示確認を新版へ流用しないよう修正。字幕の版番号チェックと再翻訳の既存試験も確認。 |
| 11 同名 | 発言と参加者一覧に同じ参加者識別タグを表示。名前・言語だけで区別しない。タグは認証の代わりではない。 |
| 12 作成者不在 | 参加者一覧で不在を明示。承認権限は移譲せず、作成者の復帰を待つ。 |
| 13 招待転送 | 参加時に任意名を入力でき、承認者に渡す。承認前は発言・履歴・名簿を配信しない既存制御を再検証。表示名は自己申告。 |
| 14 重複タブ | 認証済みの同じIDによる重複を拒否し、先のタブを使うか閉じる手順を案内。 |
| 15 データ消去 | 別認証IDは新しい申請となり、元の閲覧範囲を引き継がない。署名付き認証試験と参加境界の試験を維持。 |
| 16 言語変更 | 新しい発言に新言語を適用。過去に訳がない場合は既存の不足表示を残し、過去分を勝手に再課金しない。 |
| 17 再生音再認識 | 再生操作時、動作中のマイクを止めてから再生し、再度ONを促す。録音を勝手に再開しない。 |
| 18 キーボード・低い画面 | VisualViewportに表示高を合わせ、入力・送信・フッターがキーボードの上に残るよう調整。模擬キーボードと画面サイズ別試験を実施。 |
| 19 多言語と予算 | 選択言語数と費用の関係を参加者画面に説明。同じ言語の翻訳をまとめ、既存の管理画面の残額表示と上限を維持。 |
| 20 上限と通信障害 | AI上限・翻訳失敗・通信断の既存表示と原文保持を検証。接続不調には再接続操作を追加し、原文を消さない。 |

主な検証: npm test、check-group-chat、check-text-chat、check-text-lesson、check-keyboard、check-viewports。検証用ブラウザー・使用済み公開確認タブは終了時に閉じる。
