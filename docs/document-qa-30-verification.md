# 資料QA 30項目の検証記録

各項目は受入条件を満たした公開版を右側のブラウザで操作し、結果を記録してから完了とする。「一部確認」は下記の範囲に限る。

| 項目 | 受入条件 | 現在の証拠と残り |
|---|---|---|
| 1 | 同一PDFの既存登録と新規登録を比較 | 既存PDFの個別操作は確認済み。同一条件の比較が必要 |
| 2 | 短文・言い換えを同じ正解で採点 | 8月の下校時刻は公開版で2表現を確認。他の類型が必要 |
| 3 | 座標から縦書きの行見出しを復元 | 分割見出しの検索は導入済み。数学の質問は不合格 |
| 4 | 表の列を文字・罫線から特定 | 一部の表に既存処理あり。重点目標と取組の区別が未確認 |
| 5 | ページをまたぐ列見出しを引用 | 自動テストあり。右側ブラウザで未確認 |
| 6 | 共有URLを保って既存PDFを再解析 | 同じURLで再解析後の回答・マーカーを公開版で確認。右側ブラウザで再確認 |

| 22 | PDF文字・座標の再利用で質問時の重複解析を減らす | PDF文字の再利用は実装済み。実操作で待ち時間を比較する |

| 29 | 管理画面で資料別の待ち時間・再利用・根拠なし率を表示 | 翻訳費用の記録あり。必要な指標と管理画面表示を追加する |
| 30 | 同一の受入テストで新旧の合否と失敗を比較 | 既存の回答ベンチマークあり。30項目を対象とする比較結果を揃える |
