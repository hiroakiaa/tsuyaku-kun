# 機能変更と管理者の料金表示の確認

対象版: `20261022-cost-accounting-1`。2026-10-22に公式料金表を再確認。実請求や提供元アカウントの残高を取得したものではない。

## 今回の訂正

- 以前はセッションの全試行数を平均単価の分母にしたため、キャッシュが多いほど新しいAI翻訳の残り回数を過大評価し得た。新たに計測した、自分の発言・実測tokenあり・成功・全文AI翻訳の記録だけを試算する。
- 原文言語と訳先言語の組合せを区別する。現在の構成に合う実績がなければ未計測とし、2人の実績を多言語5人の試算へ流用しない。同じ言語は重複させず、原文言語を訳先から除く。1セッションにつき最大50件の本文なし統計に抑え、最近50件を使い、平均文字数・対象言語・単価・標本数を表示する。
- 受信した会話費用は端末の観測履歴に残るが、自分の認証IDで使える回数の試算には混ぜない。部屋の同じ発言を複数端末で合算しない。発言元の認証IDと全体予算へ1回分を計上する。
- 英語訳の非表示は表示の切替であり、翻訳費用の削減ではない。人数に比例した料金ではなく異なる訳先と文章量が影響する。
- フィリピノ語の生成音声は全体月50万文字に加えて認証ID別月5万文字がある。両方の残量を表示する。再読込・別端末・キャッシュの容量整理後は再生成が必要で、辞書の再生も永久無料ではない。
- 写真読取は全体月900回・ID別月100回・直近32日間900回を区別。写真翻訳は日次AI予算を共有し、画像上への訳文描画は端末処理。音声生成と写真読取は会話費用合計へ混ぜず月次欄で確認する。
- チャット・授業は翻訳テキストの配信。現在は音声通話・TURNを使わない。旧履歴の音声認識・中継費用は当時のスナップショットで維持する。
- 残量再取得時には最新の端末記録を使う。為替変更は日次・月次の円換算へ反映する。API取得失敗を0円と表示しない。

## 単価と範囲

定義は `web/cost-policy.js`。AI停止上限・Gemmaの単価・音声生成・OCRの上限をサーバーと表示で共用する。上限は今回増やしていない。

- [Gemmaの公式料金](https://developers.cloudflare.com/workers-ai/models/gemma-4-26b-a4b-it/): 入力100万token $0.10、出力100万token $0.30。
- [Google音声生成の公式料金](https://cloud.google.com/text-to-speech/pricing): WaveNet 100万文字 $4、公式の月次無料枠400万文字。アプリ上限とは別。他の利用も含めた無料枠の残高は未確認。
- [Google写真読取の公式料金](https://cloud.google.com/vision/pricing): Text/Document Text Detectionは月1000回まで無料、その次の帯は1000回 $1.50。アプリの月900回は独自の停止上限であり無料保証ではない。
- [Whisperの公式料金](https://developers.cloudflare.com/workers-ai/models/whisper-large-v3-turbo/): 音声1分 $0.000513。ブラウザー認識から切り替えた場合は日次AI予算も使う。

会話の端末履歴は観測した翻訳token・端末側音声認識・旧中継の推定。Google音声生成・OCR・写真のAI翻訳や他端末を含む総請求額ではない。写真のAI翻訳は日次AI残量、Googleサービスは月次欄で確認する。
