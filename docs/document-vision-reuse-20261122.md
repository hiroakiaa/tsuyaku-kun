# スキャン翻訳の資料単位の再利用

新しいVision認識・翻訳経路を /documents/:id/vision にまとめる。必ず資料の閲覧権限とページ番号を検証してから、資料ID・revision・ページをサーバーで決めたキャッシュ名前空間へ渡す。クライアントからキャッシュの共有範囲を指定させない。OCRは画像内容のハッシュ、訳文は原文・言語・辞書のハッシュで再利用する。共通資料は別利用者も同じ結果を利用できる。私有資料は閲覧権限のない利用者へ返さない。画像そのものはキャッシュ保存しない。

保存済みの翻訳は追加トークン0で返し、同時生成も1回へ集約。資料差し替え時はrevisionが変わり古い結果を混ぜない。48組のテスト合格、ユーザー間の共通資料キャッシュ、版の分離、権限とページ境界を確認。サーバー版3bcde9ba-092f-4b70-b235-0ea94cdc8440を反映済み。公開UIの別利用者検証は追記する。
