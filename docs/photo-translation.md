# 写真翻訳の運用

写真ボタンから画像を選び、必要なら四辺の範囲を絞る。送信に同意した後でのみGoogle Visionへ送信する。画像は端末内でJPEGへ変換し、長辺1800px・約2MB以内にする。PDF・複数ページ・自動連続撮影は受け付けない。

Googleへ送る機能はDOCUMENT_TEXT_DETECTIONの1種類だけ、1要求1画像。認証付きWorkerで専用シークレット `GOOGLE_VISION_API_KEY` を使用し、クライアント指定のURL・機能・APIキーは受け付けない。専用キーをVision APIだけに制限する。

全端末合計で月900回、認証IDごとに月100回。Durable Objectのトランザクションで送信前に1回を確保する。失敗・タイムアウトでも返却せず、同じ認証ID・要求IDの再送は拒否する。月の集計はUTC月初に更新するが、請求月の時差と月境界の集中送信に備えて直近32日間も900回に制限する。Google側の認証・割当拒否を検出するとその月の読取を停止する。

これはアプリ内の停止上限で、Google Cloudのアカウント全体の無料枠・請求額を保証しない。Googleへの別アプリからの要求、直接利用や他プロジェクト利用は含まない。翻訳は既存のWorkers AI日次予算を共有し、無料枠を増やさない。管理画面の概要で月の利用数・残量・認証IDごとの残量を確認できる。

読み取った原文は翻訳前に確認・編集できる。翻訳は1回1200文字までで、長い原文では利用者が部分を選択する。日本語・指定した言語・英語を表示し、数字・日付などの既存のルール確認を適用する。精度を保証する自動採点ではない。

写真・原文・訳文を新たにサーバー保存しない。サーバー保存は回数・ハッシュ化した認証ID・要求ID・時刻のみ。ページ内で同じJPEGのSHA-256が一致した場合の原文、同じ原文・言語組み合わせの訳を、それぞれ最大24件メモリーで再利用する。ページ終了・再読み込みで消え、端末間では共有しない。

テストは `npm test`。900回目を巡る同時要求、認証ID100回、月境界と32日保護、失敗時保持、同一要求IDの二重送信防止、画像本文の非保存、切抜範囲、翻訳対象の長さを検証する。接続後は架空の学校案内画像だけでOCR・原文修正・翻訳・再利用を確認する。

## 画像への訳文の重ね表示

同じDOCUMENT_TEXT_DETECTION応答に含まれる段落と座標を返し、追加のOCR要求を出さない。段落の本文と原文全体が一致する場合だけ、`/photo/translate`で最大40段落・合計1200文字を1回の予算管理付きAI要求でまとめて訳す。段落ID・必要言語の欠落や重複はエラーとし、訳文の行数で位置を推測しない。

選択言語の訳を元の段落の矩形へ白い背景帯で端末内描画する。画像生成・画像編集APIは使わない。1〜4倍に拡大でき、画像上表示のオン・オフを切り替えられる。文字が収まらない場合は「…」を表示し、全文を通常の訳文欄へ残す。傾いた文字の角度や背景自体を描き直す機能ではない。

原文を編集した場合、部分選択した場合、OCRの位置情報がない・不整合の場合は通常の翻訳表示に切り替える。画像上の位置が違う訳を出さないための制限。表示の切り替え・拡大はAPIを呼ばない。同じ段落・言語の訳はページ内で再利用する。
