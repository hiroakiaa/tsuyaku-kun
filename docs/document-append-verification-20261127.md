## 実装
- 所有者だけが追加可能。新規資料を端末内でPDF変換・抽出し、既存PDFの末尾へ結合。全ファイル成功後にPDF・本文・ページ数・資料名・版番号をDOトランザクションで一括更新。
- 元の本文の一致、版番号競合、ページ対応、合計上限を確認。大きな本文の分割保存にも対応。失敗時に一部だけ追加しない。
- 同じチャットIDとページ番号を維持。追加で版番号が変わっても会話履歴を引き継ぐ。
- 旧方式で本文だけ追加した資料は元PDFを復元できないため、黙って消さず再作成を案内。
- モデル・料金設定・予算上限・マーカーCSSを変更しない。費用への影響はcost-review.md参照。
