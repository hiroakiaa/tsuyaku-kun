# 通訳君 0.5.0

1端末の対面通訳、1対1の通話、数学の授業字幕を使えるWebアプリです。Googleログイン操作は不要です。接続の識別にはFirebaseの匿名認証を自動で使用します。

- 対面：自分と相手の言語を選んで開始。切替ボタンで話し手と言語を交代します。切替前に発話を終えてください。
- 通話：名前と両者の言語を選び、招待リンクまたはQRコードで相手を招きます。
- 授業→先生：単元を入力して「授業を作る」。4桁のルームIDが自動で表示されます。
- 授業→生徒：表示言語を選び、先生の4桁IDを入力すると自動で参加します。先頭の0と全角数字にも対応します。
- よく使う文／辞典：共通の表示言語で文例と用語を確認できます。

マイク・受信音声は停止状態で開始します。読み上げの再生・一時停止・再開・停止は文ごとのボタンで操作します。Font Awesome Free 6.5.2を使用し、点線を内側に入れた、影のないボタンと画面下のナビゲーションを採用しています。使い方・設定・ログイン画面・section-headingはありません。

## 授業のIDと保存期間

4桁IDは0000～9999から、単一のDurable Objectのストレージトランザクションで空き番号を確保します。同時作成と乱数の衝突でも、使用中のIDを上書きしません。同時に確保できるIDは最大10,000件です。

全ルームの有効期限は作成から24時間です。授業を終了しても期限は延長しません。サーバーの字幕履歴とIDは期限で削除し、番号は新しいルームに再利用します。検索時も期限を検査するため、削除処理を待たずに古いIDで参加できなくなります。終了済みの授業には新しく参加できません。

端末に保存した字幕履歴も同じ期限で、起動時・閲覧時・保存時に期限切れの項目を削除します。開いたままの画面は期限で退室し、字幕を消去します。手動でダウンロードしたCSV・JSONは利用者のファイルです。本文を含まない管理者の料金・性能集計は端末内に最大200回保存します。音声は録音保存しません。

## 仕組み

画面はGitHub Pages、通話・字幕・翻訳APIはCloudflare Workersで動作します。授業を作成した端末だけが先生として音声と字幕を送信できます。生徒の権限はサーバーで制限します。

通話音声はWebRTC＋STUN/TURN、字幕はDurable ObjectsのWebSocketを使用します。対面はWebRTC/TURNを使いません。日本語の途中字幕は既存の電話アプリのストリーミング認識を使い、切断時とその他の言語はWhisperによる区間認識に切り替えます。外国語の途中字幕には対応していません。

翻訳には原文・直前最大3文・単元・数学用語を渡し、日本語・選択言語・英語を直接生成します。対面では自分と相手の両言語を含めます。数式・数字・否定を保持し、不明な式は推測しません。失敗した字幕は再試行できます。

## スプレッドシート

[参照元](https://docs.google.com/spreadsheets/d/1Y0Je_hRWRfxgN4SoWdIla1L5uivw-9J1mhR1MYkjf8M/edit)のlanguages、phrase_cards、school_terms、lesson_correctionsを利用します。初期データは文例20件・ことば584件・数学辞書24語です。公開カタログは辞書だけを含み、個人情報や授業履歴を公開しません。

通訳君専用のApps Scriptはsheets/Code.gsです。候補はtsuyaku_term_candidatesへ送り、確認済みの数学用語だけをtsuyaku_math_glossaryのapproved行へ登録する設計です。候補の追記にはブリッジ側のデプロイとGoogleの実行権限が必要です。接続未完了や追記失敗を成功として表示しません。

## 管理者と分析

右上の管理者ボタン→1111で端末内の管理画面を開けます。1回ごとの料金目安、翻訳の試行・失敗・待ち時間、認識送信秒数、切断コードと復旧時間、音量から推定する発話末尾から字幕までの時間を記録します。

「分析を作る」→「分析をコピー」でJSONをチャットへ貼り付けられます。標準出力は名前・本文・接続キー・tokenを含めません。発言と訳を含める場合だけチェックします。料金は無料枠適用前の変動費推定で、固定費・Workers/DO・Firestore・Apps Script・他端末の音声認識を含みません。複数端末の同じルームの費用を合算しないでください。

## 開発と検証

Node.js 22以上でnpm test。36件のテストでJWT・先生と生徒の権限・字幕の配信・翻訳の再試行・料金計算・発話計測・読み上げ・4桁IDの同時発行／満員／24時間後の再利用と削除・端末履歴の期限・全画面JSの構文を確認します。npm run serveでhttp://localhost:8787を開けます。

GitHub Actionsがテスト後に画面を公開します。CloudflareのGitHub連携がwrangler.jsoncに従ってAPIを公開します。ID管理は既存TranslationRoom名前空間の専用インスタンスを使うため、新しいバインディングやマイグレーションは不要です。
